# Gate Registry

**Canonical cross-gate source:** [docs/RESULT_LEDGER.md](../docs/RESULT_LEDGER.md)  
**Method:** [docs/CANONICAL_RECORD.md](../docs/CANONICAL_RECORD.md)

This registry records the scope and disposition of completed gates. A gate number does
not by itself authorize a downstream measurement or engineering claim.

| Gate | Declared class | Scientific result | Decision |
|---|---|---|---|
| Baseline nonlinear search | \(F_0\) | Target identifiable in the declared finite interface menu; a target-aligned scalar projection identifies the scalar target. | Record scoped result |
| Hidden-state generalization | \(F_H\) | Inherited interface fails; a three-probe aggregate behavioral interface is the unique minimum in the frozen ladder. | Record boundary |
| Delay identifiability | \(F_D\) | Lag 0 fails; inherited spatial interface at lag 1 identifies the target. | Record boundary |
| Stochastic identifiability | \(F_S\) | Known stationary readout noise preserves structural identifiability; 92 repetitions per scalar observation meet the declared 0.05 criterion. | Estimation budget only |
| Hidden-plus-delay composition | \(F_{HD}\) | Unique minimum has three scalar observations at lag 1; no supra-compositional penalty or lower-cost synergy in the frozen class. | Record scoped composition |
| Nonstationary identifiability | \(F_N\) | Under known closed linear drift, two pre-target slices identify the \(t=2\) target; no interface below scalar cost 4 succeeds. | Record scoped result |

## Gate rule

The scientific sequence is:

\[
\text{Factorization}
\rightarrow
\text{Estimation}
\rightarrow
\text{Predictive validity}
\rightarrow
\text{Intervention}.
\]

A failed factorization gate blocks estimator development for that declared
\((F, L, \mathfrak I)\) branch. A successful finite-class gate does not establish
predictive validity or mechanism efficacy.
