# Research Seeds / Cross-Program Correspondence

**Status:** noncanonical research-seed layer.

This directory records post-freeze observations, candidate mathematical abstractions, cross-program correspondences, experimental hypotheses, and conceptual provenance that have not earned promotion into the canonical Interface Theory record or frozen evidence ledger.

## Standing boundary

```text
research seed
    != canonical Interface Theory
    != completed evidence
    != frozen gate result
    != earned cross-program translation
```

The canonical artifacts remain authoritative:

- `docs/CANONICAL_RECORD.md`
- `docs/RESULT_LEDGER.md`
- `docs/EVIDENCE_INDEX.md`
- `docs/roadmap.md`
- frozen Gate 013 and Gate 014 records
- `docs/protocol_foundations.md`
- the frozen Adaptive Capacity governance artifacts

Nothing in this directory modifies those records.

## Three-axis standing model

Every seed is typed along three orthogonal axes. One label must not be used as a proxy for another.

### Evidence standing

```text
SOURCE_RESULT
DERIVED_MATHEMATICAL_OBSERVATION
CANDIDATE_SHARED_SCHEMA
EXPERIMENTAL_HYPOTHESIS
CONCEPTUAL_PROVENANCE_ONLY
NOT_EVIDENCE
```

### Cross-program translation standing

```text
IDENTICAL
REFINEMENT
PROJECTION
ANALOGY
NO_TRANSLATION_EARNED
```

A translation label is never inferred from resemblance. `NO_TRANSLATION_EARNED` is a valid result, not a placeholder awaiting promotion.

### Canonical standing

Every file in this directory begins as:

```text
NONCANONICAL_RESEARCH_SEED
```

For example, this is a coherent state:

```text
CANDIDATE_SHARED_SCHEMA
+
NO_TRANSLATION_EARNED
+
NONCANONICAL_RESEARCH_SEED
```

It means that a useful common abstraction has been written down while neither source program has been rewritten into the other and no canonical claim has changed.

## Anti-promotion rules

A higher-status label must never be inferred merely from resemblance, implementation success, or repeated citation.

```text
similar notation != identical object
similar structure != refinement
finite correspondence != general law
successful architecture != target validation
provenance != causal attribution
shared abstraction != source-result identity
source-side witness != cross-program translation proof
implementation success != mechanism attribution
```

These are standing constraints, not rhetorical cautions.

## First planting

The first cross-program seed concerns an apparent shared order-theoretic structure between:

1. Interface Theory target-preserving observational interfaces; and
2. MATRIX representation/corrective safety conditions.

The current standing is intentionally conservative:

```text
Evidence standing: CANDIDATE_SHARED_SCHEMA
Translation standing: NO_TRANSLATION_EARNED
Canonical standing: NONCANONICAL_RESEARCH_SEED
```

The repair-aware bridge and adaptive-internal-interface hypothesis are recorded separately so that neither can silently upgrade the other.

## Source hierarchy

The default derivation order is:

```text
source result
    -> derived mathematical observation
    -> candidate shared schema or correspondence
    -> experimental hypothesis, if any
```

Do not rewrite this as:

```text
Interface Theory + MATRIX -> new theorem
```

A source-side result remains owned by its source program until an explicit translation argument earns otherwise.

## Conceptual provenance

The associated painting, literary/philosophical readings, public AI research essays, and cross-model critique may be preserved as idea-generating provenance.

Their standing is:

```text
CONCEPTUAL_PROVENANCE_ONLY
NOT_EVIDENCE
```

They are not evidence for any Interface Theory or MATRIX result, do not alter claim ceilings, and do not establish authorial intent for the artwork or cited authors beyond what their sources explicitly state.

## Failure path

If a correspondence cannot be typed cleanly:

```text
NO_TRANSLATION_EARNED
```

If a proposed abstraction requires assumptions absent from one source program, narrow the abstraction and record the missing assumption rather than modifying the source program to fit.

If a new scientific noun appears to be required, identify the concrete missing argument before introducing it.

## Promotion rule

A research seed may be promoted only by a separate reviewed change that explicitly supplies the missing proof, translation, finite witness, causal experiment, or implementation evidence and updates the relevant canonical artifact.

Promotion is never implicit through age, repetition, citation, implementation success, or merge history.
