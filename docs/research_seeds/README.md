# Research Seeds / Cross-Program Correspondence

**Status:** noncanonical research-seed layer.

This directory records post-freeze observations, candidate mathematical abstractions, cross-program correspondences, and hypotheses that have not earned promotion into the canonical Interface Theory record or frozen evidence ledger.

## Standing boundary

```text
research seed
    != canonical Interface Theory
    != completed evidence
    != frozen gate result
    != earned cross-program translation
```

The canonical artifacts remain authoritative:

- `docs/CANONICAL_RECORD.md`
- `docs/RESULT_LEDGER.md`
- `docs/EVIDENCE_INDEX.md`
- `docs/roadmap.md`
- frozen Gate 013 and Gate 014 records
- the frozen Adaptive Capacity governance artifacts

Nothing in this directory modifies those records.

## Purpose

The research-seed layer exists to preserve useful observations without prematurely promoting them to established results. Each entry must distinguish at least:

- source result;
- derived mathematical observation;
- candidate shared schema;
- earned translation, if any;
- experimental hypothesis;
- conceptual provenance only;
- explicit non-claims.

## Permitted standings

```text
SOURCE_RESULT
DERIVED_MATHEMATICAL_OBSERVATION
CANDIDATE_SHARED_SCHEMA
REFINEMENT
PROJECTION
ANALOGY
NO_TRANSLATION_EARNED
EXPERIMENTAL_HYPOTHESIS
CONCEPTUAL_PROVENANCE_ONLY
NOT_EVIDENCE
```

A higher-status label must never be inferred merely from resemblance. In particular:

```text
similar notation != identical object
similar structure != refinement
finite correspondence != general law
successful architecture != target validation
provenance != causal attribution
```

## First planting

The first cross-program seed concerns an apparent shared order-theoretic structure between:

1. Interface Theory target-preserving observational interfaces; and
2. MATRIX representation/corrective safety conditions.

The current standing is intentionally conservative:

```text
MATHEMATICAL COMMON SCHEMA APPARENT
CROSS-PROGRAM TRANSLATION NOT YET EARNED
```

The repair-aware bridge and adaptive-internal-interface hypothesis are recorded separately so that neither can silently upgrade the other.

## Conceptual provenance

The associated painting, literary/philosophical readings, and external discussions may be preserved as idea-generating provenance. They are not evidence for any Interface Theory or MATRIX result and do not alter claim ceilings.

## Promotion rule

A research seed may be promoted only by a separate change that explicitly supplies the missing argument or evidence and updates the relevant canonical artifact. Promotion is never implicit.
