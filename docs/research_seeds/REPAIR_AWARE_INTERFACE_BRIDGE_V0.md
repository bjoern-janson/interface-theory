# Repair-Aware Interface Bridge V0

**Evidence standing:** `CANDIDATE_SHARED_SCHEMA`

**Translation standing:** `NO_TRANSLATION_EARNED`

**Canonical standing:** `NONCANONICAL_RESEARCH_SEED`

## 1. Purpose

This record isolates a candidate bridge between two different questions:

```text
What distinctions must an interface expose to identify a target?
```

and:

```text
What distinctions must a corrective policy recover in order to repair an uncertain state?
```

The bridge is deliberately one-way and conditional. It must preserve the fact that successful correction does **not** always require identification.

```text
identifiability
!=
correctability
```

## 3. Interface Theory source object

Interface Theory asks, for declared system class `F`, interface `O`, and functional target `L`, whether there exists a decoder `\widehat L` such that

```math
L=\widehat L\circ O.
```

Equivalently,

```math
O(f_a)=O(f_b)
\Longrightarrow
L(f_a)=L(f_b).
```

An interface that merges target-different source systems cannot identify that target over the declared class.

Protocol Foundations additionally allows `O` to be generated by an adaptive interaction protocol, with the complete transcript retained as `O_P(f)`.

## 4. MATRIX source object

MATRIX does not ask only whether a hidden state can be identified.

For fixed system state `G` and budget `B`, it asks whether one executable policy can begin from uncertainty over a whole set `S`, choose diagnostics, and achieve valid repair for every state in `S` within budget:

```math
\Phi_B(G)
=
\left\{
S\subseteq\Omega:
\exists\pi,
\mathrm{cost}(\pi)\le B,
\ \forall x\in S,
\ \pi\text{ diagnoses and validly repairs }x
\right\}.
```

The representation is safe when every uncertainty cell it induces lies in that frontier.

## 5. Blind-repair caveat

Identification is not necessary when one repair works for every member of the uncertainty set.

For a simplified terminal or one-step model, let

```math
R(x)\subseteq A
```

be the set of valid terminal repairs for state `x`.

Blind repair is possible on uncertainty set `S` when

```math
\boxed{
\bigcap_{x\in S}R(x)\neq\varnothing.
}
```

Any action in that intersection repairs every possible state in `S` without distinguishing which state occurred.

Therefore the statement

```text
interfaces are necessary for correction
```

is too strong.

The restricted statement is:

```text
an identifying or refining interface is needed only to the extent that successful correction must condition on distinctions within the current uncertainty set.
```

## 6. Static repair-aware sufficiency

Suppose a declared observation map

```math
O:S\to H
```

induces observational cells

```math
C_h=O^{-1}(h).
```

In the simplified one-step repair model, the observation is sufficient for valid terminal repair when every observational cell admits a common repair:

```math
\boxed{
\forall h\in O(S),
\quad
\bigcap_{x\in C_h}R(x)\neq\varnothing.
}
```

A selector may then choose one valid repair `a_h` for each transcript class `h`.

This condition is relation-valued rather than target-valued. It does not require the observation to identify the exact hidden state.

## 7. Relationship to ordinary factorization

A functional-target special case can be recovered when each state has one required target label or one required repair class.

For example, if there is a functional repair target

```math
L_R:S\to\mathcal T_R
```

and valid repair requires choosing the unique class `L_R(x)`, then repair-aware sufficiency reduces to target homogeneity on every observation cell:

```math
O(x)=O(y)
\Longrightarrow
L_R(x)=L_R(y).
```

That is ordinary Interface Theory factorization for the declared repair target.

But MATRIX permits richer cases:

- several actions may validly repair one state;
- one action may repair several states;
- diagnosis may be adaptive;
- repair may occur after multiple observations and actions;
- future actions may consume resources;
- validity depends on the declared repair relation and task family;
- one current ambiguity may be safe because future interaction can reopen it.

Therefore no general translation from MATRIX correction to a single functional target has been earned.

## 8. Adaptive continuation view

The one-step intersection condition is only a boundary case.

In a sequential setting, a partial transcript `h` induces a residual uncertainty set

```math
S_h\subseteq\Omega
```

plus some remaining corrective resources

```math
B_h.
```

The relevant question is not necessarily whether `h` identifies the hidden state. It is whether there exists a valid continuation policy from that residual state of knowledge and resources.

Schematically:

```math
\boxed{
\operatorname{Adeq}_{\mathrm{cont}}(h)
\iff
\exists\pi_h
\text{ such that }
\pi_h
\text{ validly repairs every }x\in S_h
\text{ within }B_h.
}
```

This is only a schematic restatement of the kind of existence condition already represented by `\Phi_B(G)`; it does not define a new MATRIX kernel object.

The candidate bridge is therefore:

```text
Interface Theory:
observation cells must be homogeneous for the declared target

repair-aware special case:
observation cells must support a common valid terminal repair

MATRIX general case:
residual uncertainty plus remaining resources must support a valid continuation policy
```

## 9. When identifiability becomes load-bearing

Suppose two states `x,y\in S` satisfy

```math
R(x)\cap R(y)=\varnothing
```

in the one-step model.

Then no blind terminal repair can succeed on both. Any successful policy must either:

1. obtain information that separates them before choosing the terminal repair; or
2. transform the state through some earlier action so that a later common valid repair becomes available.

Thus state-identifying information is not intrinsically necessary, but **decision-relevant discrimination** becomes necessary whenever the available policy topology contains no state-independent valid continuation.

This distinction matters for later MATRIX selector-conflict work:

```text
hidden state difference
!= hidden certificate difference
!= distinct viable policy requirement
```

A hidden distinction matters to action selection only when it changes the set of viable continuations under the declared contract.

## 10. Candidate bridge statement

The strongest statement admitted here is:

```math
\boxed{
\text{Interfaces create corrective possibility for distinctions that cannot be repaired blind,}
}
```

provided `create` is read operationally and narrowly:

```text
an available observation/intervention route can refine a corrective uncertainty set enough to make a valid continuation policy available.
```

Even this wording is a research-seed bridge, not a canonical theorem.

A safer fully explicit form is:

```text
If no state-independent valid continuation exists over an uncertainty set, then a successful corrective policy must obtain or induce some distinction that changes the available valid continuation structure before the incompatible repair choice is made.
```

## 11. Why translation remains unearned

The Interface Theory factorization criterion has a declared functional target `L`.

The MATRIX corrective frontier quantifies over executable policies, adaptive diagnostics, repair validity, cost, and budget.

No mapping has yet shown that all of those MATRIX semantics can be preserved by one Interface Theory target/interface pair without collapsing load-bearing distinctions.

Accordingly:

```text
CANDIDATE_SHARED_SCHEMA
+
NO_TRANSLATION_EARNED
+
NONCANONICAL_RESEARCH_SEED
```

remains the standing.

## 12. Non-claims

This record does not claim:

- identifiability is necessary for all correction;
- exact hidden-state identification is necessary for adaptive repair;
- the one-step repair-intersection condition replaces `\Phi_B(G)`;
- a diagnostic interface is sufficient without compatible policy and repair machinery;
- a state distinction matters merely because it exists;
- Interface Theory already contains MATRIX's corrective frontier;
- MATRIX is a refinement of Interface Theory;
- any particular neural interface improves corrective capacity.

## 13. Next legal test

A future finite construction could deliberately create two hidden situations that are both solvable, but whose viable policy sets are nonempty and disjoint under the declared contract:

```math
\mathcal C_Q(G_1)\neq\varnothing,
\qquad
\mathcal C_Q(G_2)\neq\varnothing,
\qquad
\mathcal C_Q(G_1)\cap\mathcal C_Q(G_2)=\varnothing.
```

Such a witness would make a hidden distinction policy-relevant without relying on an intrinsically infeasible branch.

That would still be a new finite construction, not evidence that the current source programs already instantiate the bridge generally.
