# Protocol Foundations

**Status:** minimal deterministic execution substrate beneath Interface Theory.

## Scope and layer boundary

Protocol Theory determines which observations are realizable relative to a
declared system execution and legality structure. It does not certify that the
declaration matches external physical or legal constraints, and it does not
determine whether a target is identifiable, estimable, predictive, or causally
useful.

Fix a nonempty declared class of systems \(F\). For every protocol \(P\)
admissible over \(F\), deterministic execution induces an observation map
\(O_P\). The admissible observation family is

\[
\mathcal O_{\mathrm{adm}}(F)
=
\left\{
O_P:P\text{ is admissible over }F
\right\}.
\]

This is a set of observation maps: distinct protocols that induce the same map
appear only once. That extensional collapse is sufficient for the present
Interface Theory boundary. Protocol identity and implementation-specific
properties are outside this foundation.

Interface Theory receives

\[
(F,L,\mathcal O_{\mathrm{adm}}(F))
\]

and may then ask whether, for some admissible \(P\), there exists a map

\[
\widehat L:O_P(F)\longrightarrow\mathcal T
\]

such that

\[
L=\widehat L\circ O_P.
\]

That downstream question does not add anything to the execution semantics
defined here. This foundation contains exactly the following five conceptual
primitives.

## 1. System execution structure

Let \(A\) be a common intervention alphabet and \(Y\) a common observation
alphabet for the declared class \(F\). For each \(f\in F\), its deterministic
execution structure is

\[
\mathcal S_f
=
(X_f,x_f^0,A,Y,\operatorname{Adm}_f,\operatorname{Step}_f),
\]

where:

- \(X_f\) is the state space of \(f\);
- \(x_f^0\in X_f\) is its initial state;
- \(\operatorname{Adm}_f(x)\subseteq A\) is the set of interventions legal at
  state \(x\);
- \(\operatorname{Step}_f\) is the deterministic partial transition/readout
  function

  \[
  \operatorname{Step}_f:
  \left\{(x,a)\in X_f\times A:a\in\operatorname{Adm}_f(x)\right\}
  \longrightarrow X_f\times Y.
  \]

If

\[
\operatorname{Step}_f(x,a)=(x',y),
\]

then performing legal intervention \(a\) at state \(x\) moves the system to
\(x'\) and emits observation \(y\). The function is not defined for illegal
state-action pairs.

## 2. Transcript

A transcript is a finite action/readout history

\[
h=
\bigl((a_1,y_1),\ldots,(a_n,y_n)\bigr)
\in(A\times Y)^*.
\]

The empty transcript is denoted by \(\epsilon\). If \(h\in(A\times Y)^*\), its
extension by one action/readout pair is written

\[
h\mathbin{\|}(a,y).
\]

A transcript need not be reachable under every system or protocol. Reachable
transcripts are generated by the execution rule below.

## 3. Protocol

Let \(\texttt{stop}\notin A\). A deterministic adaptive protocol is a total
policy

\[
P:(A\times Y)^*\longrightarrow A\cup\{\texttt{stop}\}.
\]

At a transcript \(h\), the value \(P(h)\) either selects the next intervention
or terminates interaction. Because \(P\) receives the complete transcript, its
next intervention may depend on every action and observation generated so far.

Totality specifies the policy on all finite transcripts, including transcripts
that no declared system can generate. Protocol admissibility is evaluated only
along executions actually reachable from the declared initial states.

## 4. Execution

For a protocol \(P\) and system \(f\), initialize

\[
x_0=x_f^0,
\qquad
h_0=\epsilon.
\]

Given \((x_t,h_t)\), evaluate \(P(h_t)\). This generates one unique maximal
attempted run according to the following cases.

- If \(P(h_t)=\texttt{stop}\), execution terminates and returns \(h_t\).
- Otherwise write \(P(h_t)=a_{t+1}\). If

  \[
  a_{t+1}\notin\operatorname{Adm}_f(x_t),
  \]

  the attempted run is blocked at \((h_t,a_{t+1})\) by an illegal request.
  If the action is legal, execute

  \[
  (x_{t+1},y_{t+1})
  =
  \operatorname{Step}_f(x_t,a_{t+1})
  \]

  and extend the transcript by

  \[
  h_{t+1}=h_t\mathbin{\|}(a_{t+1},y_{t+1}).
  \]

If legal steps continue forever without \(\texttt{stop}\), the attempted run
diverges. Because \(P\) and \(\operatorname{Step}_f\) are deterministic, the
maximal attempted run is unique.

A protocol \(P\) is **admissible over \(F\)** when, for every \(f\in F\):

1. its maximal attempted run is never blocked by an illegal request; and
2. it reaches \(\texttt{stop}\) after finitely many steps rather than
   diverging.

For an admissible protocol, \(\operatorname{Exec}(P,f)\) denotes the unique
finite transcript returned by this recursion. If either condition fails,
\(\operatorname{Exec}(P,f)\) is not defined in this foundation.

## 5. Protocol-generated observation

For every protocol \(P\) admissible over \(F\), define

\[
\boxed{
O_P:F\longrightarrow(A\times Y)^*,
\qquad
O_P(f)=\operatorname{Exec}(P,f).
}
\]

The complete transcript is the observation. No summary statistic, feature map,
or decoder is built into \(O_P\).

For a separately declared target \(L:F\to\mathcal T\), Interface Theory may
subsequently test the target-preservation condition

\[
O_P(f)=O_P(g)
\Longrightarrow
L(f)=L(g).
\]

This statement is only the downstream layer boundary; no identification
theorem is asserted here.

## Minimal deterministic execution example

Let

\[
F=\{f_0,f_1\},
\qquad
A=\{\mathsf{inspect},\mathsf{confirm}_0,\mathsf{confirm}_1\},
\qquad
Y=\{0,1,\mathsf{ok}\}.
\]

For \(b\in\{0,1\}\), let \(X_{f_b}=\{0,1,2\}\), with initial state
\(x_{f_b}^0=0\). Define the legal actions and steps by

\[
\operatorname{Adm}_{f_b}(0)=\{\mathsf{inspect}\},
\qquad
\operatorname{Step}_{f_b}(0,\mathsf{inspect})=(1,b),
\]

\[
\operatorname{Adm}_{f_b}(1)=\{\mathsf{confirm}_b\},
\qquad
\operatorname{Step}_{f_b}(1,\mathsf{confirm}_b)=(2,\mathsf{ok}),
\]

and \(\operatorname{Adm}_{f_b}(2)=\varnothing\).

Define the total policy

\[
P(h)=
\begin{cases}
\mathsf{inspect}, & h=\epsilon,\\
\mathsf{confirm}_b,
  & h=((\mathsf{inspect},b)),\ b\in\{0,1\},\\
\texttt{stop}, & \text{otherwise}.
\end{cases}
\]

The first observation determines which confirmation action the protocol
requests. Therefore \(P\) is admissible over both systems, and

\[
\operatorname{Exec}(P,f_b)
=
\bigl(
(\mathsf{inspect},b),
(\mathsf{confirm}_b,\mathsf{ok})
\bigr).
\]

This example illustrates only deterministic adaptive execution and transcript
generation.

## Explicit non-goals

This foundation does not define or assume:

- protocol composition or a protocol algebra;
- protocol equivalence;
- simulation or refinement preorders;
- resource costs or resource preorders;
- stochastic execution or nondeterminism;
- concurrency or partial-order histories;
- autonomous evolution, silent transitions, initial emissions, durations, or
  clocks, unless encoded explicitly into the declared states, interventions,
  and readouts;
- cloning, resets, or multiple-specimen semantics;
- protocol incompatibility;
- amalgamation or non-amalgamation;
- estimation or statistical inference;
- learning or adaptation;
- predictive validity;
- mechanism efficacy;
- theorem statements.

## Hostile redundancy audit

**Verdict:** this protocol object is standard deterministic interactive-system
semantics. No novelty is claimed for the substrate.

- **Labelled transition systems:** each legal pair \((x,a)\) determines a
  labelled state transition with an emitted readout. The present notation adds
  an explicit legality map and fixes a deterministic transition.
- **Deterministic automata and transducers:**
  \(\operatorname{Step}_f\) is a partial deterministic Mealy-style
  transition/output function, while \(P\) supplies inputs as a function of the
  observed history.
- **Process semantics:** \(\operatorname{Exec}(P,f)\) is the finite trace
  semantics of coupling a deterministic controller to a deterministic process.
  No process equivalence, bisimulation, or algebra is introduced.
- **Adaptive experimental design:** the history-dependent policy has the usual
  adaptive form, but there is no uncertainty model, design objective,
  estimator, or optimization criterion.
- **Causal intervention frameworks:** actions may be interpreted as physical
  interventions, but this foundation declares no causal graph, potential
  outcomes, do-calculus, or counterfactual semantics.

The purpose of the definition is therefore conventional rather than novel: it
fixes one executable semantics from which the admissible observation family
\(\mathcal O_{\mathrm{adm}}(F)\) can be derived. Any novelty must arise in later
results about constrained experimental construction or target-relative
identification, not in this substrate.
