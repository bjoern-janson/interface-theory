# Archived illustrative specification: hidden state

**Status:** noncanonical. This directory is retained as a design sketch and
must not be cited as the completed hidden-state gate.

The frozen hidden-state result is recorded in
[docs/RESULT_LEDGER.md](../../docs/RESULT_LEDGER.md): the inherited (F_0)
interface fails, while the unique minimum in the declared finite ladder is

\[
\{-1,0,1\}\times\{r_\Sigma\},
\]

with scalar observation cost three.

That result trades two readouts at one probe for one aggregate readout at three
probes. It is not a generic claim that hidden state requires an additional
channel, a future-response feature, or a belief estimator.

Any replacement must declare (F), (O), (L), the finite interface family,
and the factorization test before reporting a minimum.
