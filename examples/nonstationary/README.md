# Archived illustrative specification: nonstationarity

**Status:** noncanonical. This directory is retained as a design sketch and
must not be cited as the completed nonstationary gate.

The frozen result is a closed known-linear-drift class, not a hidden Markov
regime, change-detection, adaptive-window, or self-updating-interface study.
Its held-out target is the coefficient vector at (t=2). One pre-target
slice fails; two slices at (t=0,1) identify the target in the declared
class.

The condition is temporal-design coverage:

\[
\phi(T)\in\operatorname{rowspan}(X_{\mathcal T}),
\]

together with spatial target observability. The frozen audit evaluated 150
interfaces; 26 identify the target and none below scalar cost four does.

A future nonstationary gate must include time and history in the declared
domain of (O). It cannot condition a predictor on a hidden regime variable
unless that variable or a valid observable proxy is part of the interface.
